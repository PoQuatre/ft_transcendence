## Development setup

Install and activate [Mise](https://mise.jdx.dev/), then install either `uv`
or `pipx` for Mise's `pypi:` backend. The project uses the following host
tools:

- Podman with the `podman compose` provider
- GNU Make
- Mise, activated in the shell that runs the project commands
- Either `uv` or `pipx`
- A C/C++ compiler, such as Clang
- Ninja

From the repository root, install the pinned toolchain and project
dependencies, trust the local development certificate authority, then start
the development stack:

```sh
mise install
mkcert -install
make setup
make dev
```

Open <https://localhost:8443>. `mkcert -install` is a one-time per-machine
step; it lets the browser trust the certificates generated by `make dev`.
`make certs` retains the issuer key at the ignored, owner-readable-only path
`certs/rootCA-key.pem` so Vault can enroll that local CA.

Podman and `podman compose` are the supported container runtime. Docker with
Docker Compose may work with, for example, `make DOCKER=docker dev`, but it is
not tested.

## Production-like setup

This stack is for local production-like or evaluation use, not public internet
deployment. HAProxy is the host-networked TLS passthrough ingress on port
`8443`; nginx remains on Podman's internal networks and its port is published
only to `127.0.0.1:9443`. It uses local TLS certificates.

Install these host tools:

- Podman with the `podman compose` provider
- GNU Make
- OpenSSL, when local certificates do not already exist and `mkcert` is not
  available

Start the stack from the repository root:

```sh
make start
```

This creates a local `.env` with generated secrets and local certificates when
they are missing. Open <https://localhost:8443>. When `mkcert` is unavailable,
the certificate is generated with OpenSSL and the browser will show a
certificate warning. The generated root key remains in the ignored `certs/`
directory for Vault PKI enrollment.

# Lobby control protocol

After WebRTC connects, send JSON text on the reliable `control` channel:

- `{"type":"QuickPlayRequest"}` joins an available lobby (up to eight players), creating one if necessary. Repeating the request returns the current state.
- `{"type":"LeaveGameRequest"}` leaves the lobby without closing WebRTC; the server replies with `{"type":"GameLeft"}`.
- On join or leave, each remaining member receives `{"type":"LobbyState","lobbyId":"...","players":[{"id":"...","username":"..."}]}`. Invalid or unsupported messages receive `{"type":"Error","error":"..."}`.

An authenticated offer uses the login session cookie; bearer tokens and other `Authorization` headers are rejected with HTTP 401. Missing credentials create a guest; invalid or expired credentials return HTTP 401. A second connection for the same account returns HTTP 409. Lobby state is in memory and is lost on server restart.

## Authoritative movement

Each quick-play lobby owns a 60 Hz server-side Ark/Box2D world. The browser sends
sequenced movement and aim inputs on the unreliable state channel; the server
normalizes movement, stops it after 500 ms without new input, and sends complete
player states at 20 Hz. States carry the session generation, server tick, local
entity ID and last input ID. The client ignores old states and renders the latest
one without simulating movement. Complete states repair packet loss and player
departures without relying on a prior delta. Positions and velocities are signed
16-bit hundredths of a Box2D metre; the renderer uses 20 pixels per metre.

The `full_state` flag distinguishes these independent updates from future
baseline-relative deltas. Interpolation can buffer server ticks; prediction and
reconciliation can retain input IDs and replay inputs after the acknowledged
ID. These are not implemented.

Hold left click to fire and press Shift while moving to dash. The server
enforces a three-shots-per-second fire rate and a two-second dash cooldown.
Projectiles damage players and resources; depleted players immediately respawn,
and destroyed resources respawn at random locations after ten seconds. Circle
and square resources drift, rotate, and can be pushed by players or shots. The
server caps active projectiles at 48 per lobby. Complete state packets may be up
to 8 KiB; the current approach favors simplicity over bandwidth efficiency.
