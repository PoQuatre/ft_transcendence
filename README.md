## Development setup

Install and activate [Mise](https://mise.jdx.dev/), then install either `uv`
or `pipx` for Mise's `pypi:` backend. The project uses the following host
tools:

- Podman with the `podman compose` provider
- GNU Make
- Mise, activated in the shell that runs the project commands
- Either `uv` or `pipx`
- A C/C++ compiler, such as Clang
- Ninja

From the repository root, install the pinned toolchain and project
dependencies, trust the local development certificate authority, then start
the development stack:

```sh
mise install
mkcert -install
make setup
make dev
```

Open <https://localhost:8443>. `mkcert -install` is a one-time per-machine
step; it lets the browser trust the certificates generated by `make dev`.

Podman and `podman compose` are the supported container runtime. Docker with
Docker Compose may work with, for example, `make DOCKER=docker dev`, but it is
not tested.

## Production-like setup

This stack is for local production-like or evaluation use, not public internet
deployment. It listens only on `127.0.0.1:8443` and uses local TLS
certificates.

Install these host tools:

- Podman with the `podman compose` provider
- GNU Make
- OpenSSL, when local certificates do not already exist and `mkcert` is not
  available

Start the stack from the repository root:

```sh
make start
```

This creates a local `.env` with generated secrets and local certificates when
they are missing. Open <https://localhost:8443>. When `mkcert` is unavailable,
the certificate is generated with OpenSSL and the browser will show a
certificate warning.
